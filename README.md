## 🌟 核心特色

- **秒级真太阳时计算**：整合地球轨道偏心率与 23.44° 黄赤交角，动态实时补偿时差方程 (EOT -14.3m ~ +16.4m) 与全国 3,000+ 区县地理时差。
- **10 部传世典籍索隐**：内置《穷通宝鉴》《滴天髓阐微》《子平真诠评注》《三命通会》《渊海子平》等，1,547 条分类文献智能索引与调候用神深度关联。
- **Apple HIG 原生体验**：
  - macOS：12px 连续曲率圆角 (Squircle)、原生交通灯交互、深邃悬浮弥散空间阴影。
  - iOS：原生 SwiftUI 打造，iOS 17+ 专属悬浮晶莹胶囊 Dock。
- **隐私至上 · 本地私有算力**：纯 Rust 算法内核离线推演，数据完全保存在本地 SQLite，绝不上传个人生辰八字。
